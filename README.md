# Gestão de Projetos & PMO — Swap

Material de consulta + app de operação para acompanhar projetos.
Este repositório hospeda **apenas a ferramenta**. Os dados preenchidos no app
(matriz, RICE, status) são salvos na pasta/Drive de cada pessoa — **nada é
enviado para o site nem para servidores**.

## Arquivos
- `index.html` — página inicial (leva aos dois abaixo)
- `Material-de-Consulta.html` — conteúdo de estudo
- `App-de-Operacao.html` — matriz, RICE, status e dashboard
- `Guia de Uso - Leia Primeiro.docx` — manual de uso

---

## Como publicar no GitHub Pages (pela web, sem instalar nada)

1. **Crie uma conta** em https://github.com (se ainda não tiver).
2. Clique em **New repository** (botão verde ou o "+" no topo direito).
   - **Repository name:** por exemplo `swap-gestao-projetos`
   - **Visibilidade:** *Public* (Pages grátis) ou *Private* (Pages privado exige
     plano pago/organização).
   - Clique em **Create repository**.
3. Na página do repositório vazio, clique em **uploading an existing file**
   (ou **Add file → Upload files**).
4. **Arraste os arquivos** deste pacote para a área de upload
   (`index.html`, `Material-de-Consulta.html`, `App-de-Operacao.html`,
   `README.md` e, se quiser, o `.docx`).
5. Clique em **Commit changes**.
6. Vá em **Settings → Pages** (menu lateral).
   - Em **Source**, escolha **Deploy from a branch**.
   - Em **Branch**, selecione **main** e a pasta **/ (root)**. Clique em **Save**.
7. Aguarde ~1 minuto e recarregue a página. Vai aparecer o link, algo como:
   `https://SEU-USUARIO.github.io/swap-gestao-projetos/`
8. **Pronto!** Compartilhe esse link com o time.

### Para atualizar depois
Abra o repositório → **Add file → Upload files** → arraste a nova versão →
**Commit**. O link se atualiza sozinho em ~1 minuto.

## Importante
- Mantenha os três HTML no mesmo repositório (eles se conectam por links).
- Use **Chrome** ou **Edge** para o recurso de "conectar pasta" do app funcionar.
- No app, aponte o armazenamento para uma pasta do **Drive/OneDrive da Swap**
  para manter os dados privados e compartilhados só com o time.
